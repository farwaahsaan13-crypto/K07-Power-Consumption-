K07 Power Consumption - installable app (PWA)
1. Upload this whole folder to any HTTPS host (free: Netlify Drop https://app.netlify.com/drop , GitHub Pages, Cloudflare Pages).
2. Open the link on the phone/PC.
   Android/Chrome: menu > Install app (or the "Install app" button in the page).
   Windows/Chrome/Edge: install icon in the address bar.
   iPhone/Safari: Share > Add to Home Screen.
3. After first open it works offline. Data stays on that device.
